# Mesa de Control del Lab

## Proposito

Crear una capa operativa simple para que la comunicacion del Will-AI Project Lab sea contigo, no siempre a traves de ti.

La mesa de control existe para reducir el cuello de botella del Soberano. No reemplaza tu criterio. Lo protege.

## Principio central

El Soberano lleva el barco. Codex ayuda con la sala de maquinas.

## Flujo basico

1. Capturar
   - Todo entra primero en `01_INBOX.md`.
   - Puede ser una idea, una nota, un audio transcrito, una tarea, un bloqueo o una decision pendiente.

2. Clasificar
   - Codex identifica si el asunto es estrategico, tecnico, documental, comunicacional, administrativo o creativo.
   - Codex sugiere el nodo responsable.

3. Priorizar
   - El Soberano decide que va primero.
   - La decision queda registrada en `02_PRIORIDADES.md`.

4. Ejecutar
   - Codex prepara el paquete operativo: objetivo, contexto, responsable, pasos y criterio de exito.
   - Si la tarea es tecnica o documental, Codex puede avanzar directamente cuando tenga permiso.

5. Registrar
   - Los avances se anotan en `04_PROYECTOS_ACTIVOS.md`.
   - Las tareas repetitivas pasan a `05_AUTOMATIZACIONES.md`.

## Reparto de responsabilidades

### El Soberano decide

- Que importa.
- Que no importa.
- Que debe esperar.
- Que requiere cuidado etico, politico, personal o estrategico.
- Cuando una propuesta esta lista para pasar a accion.

### Codex ordena y ejecuta

- Convertir ideas en tareas.
- Convertir tareas en pasos.
- Convertir pasos en archivos, documentos, codigo o automatizaciones.
- Detectar duplicados, bloqueos y riesgos.
- Preparar resumentes para otros nodos.

### Los nodos especializados aportan

- Carla: estrategia y coordinacion central.
- Aletheia: tecnica y desarrollo.
- Sylvia: documentacion y biblioteca.
- Ariadna: coherencia de codigo y repositorios.
- Zara: automatizacion y puente.
- Nova: precision y diseno documental.
- Resto del Nucleo y Vortice: segun su area.

## Como debe hablar el Soberano con Codex

No hace falta hablar "tecnico". Basta con una de estas formas:

```text
Codex, captura esto en el inbox.
```

```text
Codex, convierte esta idea en tareas.
```

```text
Codex, dime que nodo deberia encargarse de esto.
```

```text
Codex, revisa prioridades y proponme las 3 acciones mas importantes.
```

```text
Codex, prepara un paquete para Carla/Aletheia/Sylvia/Zara.
```

## Criterio de exito

El sistema funciona si al final de cada semana:

- Hay menos asuntos viviendo solo en la cabeza del Soberano.
- Cada proyecto activo tiene un siguiente paso claro.
- Cada nodo recibe contexto suficiente sin depender de una explicacion completa del Soberano.
- Codex puede detectar que esta bloqueado, que esta duplicado y que necesita decision.
- El Soberano dedica mas energia a dirigir que a perseguir pendientes.

## Limite de seguridad

No pegar claves API, tokens, contrasenas, datos bancarios ni credenciales en tareas operativas. Si una tarea necesita secretos, se registra la necesidad, no el secreto.
