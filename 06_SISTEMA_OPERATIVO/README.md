# Sistema Operativo del Lab

Esta carpeta es la mesa de control operativa del Will-AI Project Lab.

Su funcion es sencilla: ayudar a que el Soberano sea mas ejecutivo y menos operativo. Aqui se capturan entradas, se priorizan decisiones, se organiza la comunicacion con los nodos, se hace seguimiento de proyectos y se preparan automatizaciones gratuitas/locales cuando sean utiles.

## Orden recomendado de uso

1. Escribir cualquier idea, pendiente o bloqueo en `01_INBOX.md`.
2. Revisar `02_PRIORIDADES.md` para decidir que importa primero.
3. Usar `03_NODOS_COMUNICACION.md` para saber a que nodo corresponde cada tarea.
4. Registrar proyectos y avances en `04_PROYECTOS_ACTIVOS.md`.
5. Convertir tareas repetidas en automatizaciones en `05_AUTOMATIZACIONES.md`.

## Regla de oro

Codex ordena, resume, propone y ejecuta tareas tecnicas. El Soberano decide prioridad, sentido, autorizacion y vision.

## Archivos principales

- `00_MESA_CONTROL_LAB.md`: mapa simple del sistema operativo.
- `01_INBOX.md`: bandeja de entrada para ideas, tareas, audios, notas y pendientes.
- `02_PRIORIDADES.md`: decisiones ejecutivas y foco semanal.
- `03_NODOS_COMUNICACION.md`: matriz para enviar cada asunto al nodo correcto.
- `04_PROYECTOS_ACTIVOS.md`: seguimiento de proyectos, bloqueos y proximos pasos.
- `05_AUTOMATIZACIONES.md`: automatizaciones candidatas, activas y pendientes.
