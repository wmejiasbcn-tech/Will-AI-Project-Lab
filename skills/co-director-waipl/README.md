## Para qué se carga

Cuando el encargo es rodar un corto del ecosistema, un storyboard con continuidad entre planos, o usar Co-Director. No se carga para una imagen fija, un icono o el blasón.

El corte antes de publicar sigue siendo de Will o de Carla.
