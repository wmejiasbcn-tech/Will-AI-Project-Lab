## Finalidad del expediente

Este directorio conserva el estudio de viabilidad e implementación de dos hipótesis experimentales:

- **Sistema G3 / Supersistema G3:** hipótesis de una capa interrelacional que pueda correlacionar estructura, validez temporal, actos/atestación, identidad/autorización y evidencia bajo reglas fail-closed.
- **ALNIRA:** hipótesis de una capacidad experimental formalmente aislada, reproducible, trazable y epistemológicamente contenida para modelización, simulación y exploración de escenarios.

La documentación se conserva aunque cualquiera de las dos hipótesis termine en NO-GO. El cierre negativo también es un resultado de I+D+I+e+A y debe quedar trazabilizado.

## Regla metodológica

No se considera que una capacidad existente cubra una garantía G3 o ALNIRA por mera semejanza nominal. La comparación debe hacerse por:

**estado + función equivalente + jurisdicción + alcance + garantías + comportamiento ante fallo + evidencia de operación/validación.**

Asimismo:

- DOCUMENTADO ≠ EXISTENTE ≠ EJECUTABLE ≠ OPERATIVO ≠ VALIDADO.
- CAPACIDAD TÉCNICA ≠ PERMISO ≠ AUTORIZACIÓN.
- Simulación ≠ hecho canónico.
- Inferencia ≠ hecho.
- Log ≠ atestación suficiente por sí mismo.
