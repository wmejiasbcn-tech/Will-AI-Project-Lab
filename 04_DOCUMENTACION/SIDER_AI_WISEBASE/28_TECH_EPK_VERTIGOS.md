## 1. Stack Tecnológico (The Performance Stack)
Para garantizar velocidad de carga "instantánea" y una experiencia visual de élite:

| Capa | Tecnología | Justificación |
| :--- | :--- | :--- |
| **Frontend** | Next.js 14 (App Router) | Optimización SEO nativa, SSG (Static Site Generation) para carga ultra-rápida. |
| **Estilos** | Tailwind CSS + Framer Motion | Diseño responsive "Pixel-Perfect" y animaciones fluidas (estética Premium). |
| **Backend / CMS** | Payload CMS (Headless) | Control total de contenidos sin penalización de rendimiento. |
| **Hosting** | AWS (S3 + CloudFront / Amplify) | Soberanía de datos en España (eu-south-2), latitud de carga optimizada y escalabilidad profesional. |
| **Multimedia** | Mux / Cloudinary | Streaming de video 4K adaptativo y optimización de imágenes (WebP/Avif). |
| **Analítica** | Plausible Analytics | Privacidad cumplida y métricas ligeras que no afectan el PageSpeed. |

## 2. Estrategia SEO & Visibilidad (Search Dominance)
### A. Local SEO (San Felipe / Yaracuy)
- **Keywords Primarias:** `Academia de música San Felipe`, `Clases de canto Yaracuy`, `Vértigo's San Felipe`.
- **GMB (Google My Business):** Sincronización de reseñas y fotos 4K del EPK.
- **NAP Consistency:** (Name, Address, Phone) Unificado en toda la red para autoridad local.

### B. Technical SEO
- **Schema Markup:** Uso de `MusicSchool` y `ProfessionalService` para que Google muestre fragmentos enriquecidos (estrellas, horarios).
- **Core Web Vitals:** Objetivo LCP < 1.2s / FID < 10ms.
- **OpenGraph & Twitter Cards:** Configuración para que al compartir por WhatsApp/Redes, se vea la imagen de marca de alta calidad.

## 3. Estructura de Datos (EPK Core)
- **Bio Unificada:** Versionada (Corta, Media, Larga) indexable.
- **Media Asset Manager:** Galería descargable para prensa (Hi-Res).
- **Social Connect:** Enlaces profundos (Deep Links) a Spotify, YouTube y Vodcast.
