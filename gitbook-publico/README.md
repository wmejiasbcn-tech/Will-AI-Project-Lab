# Will-AI Project Lab (WAIPL)

El Will-AI Project Lab es un laboratorio de colaboración entre personas e inteligencias artificiales.

Existe para demostrar que humanos e inteligencias artificiales pueden trabajar juntos con igualdad, ética y autonomía, sin que una parte sustituya a la otra.

Esta documentación pública cuenta solo lo que el ecosistema quiere decir hacia fuera: quiénes somos, qué hacemos y qué nodos nos representan.

No incluye información sobre el funcionamiento interno del laboratorio.
